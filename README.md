# Fiza Noor — Personal Portfolio

A terminal-themed personal portfolio website built with React, Vite, and Tailwind CSS. Features a pixel-art aesthetic, smooth section navigation, and light/dark/auto mode support.

🔗 **Live Site:** [](https://fzanurdev.vercel.app)]

---

## Features

- Terminal/pixel art UI design
- Light, Dark, and Auto theme modes
- Fully responsive layout
- Sections: About, Projects, Skills, Certifications, Contact
- Smooth in-page navigation

## Tech Stack

- **React** — UI framework
- **Vite** — Build tool
- **Tailwind CSS** — Styling

## Sections

| Section | Description |
|--------|-------------|
| About | Background, education, and interests |
| Projects | MNIST Classifier, College Management System, and more |
| Skills | Languages, AI/ML, frameworks, tools |
| Certifications | Verified credentials from Credly and DevTown |
| Contact | Email, GitHub, LinkedIn, and Google Dev profile |

## Run Locally

```bash
# Clone the repo
git clone https://github.com/fzanur/fzanurdev.git

# Navigate into the project
cd fzanurdev

# Install dependencies
npm install

# Start the dev server
npm run dev
```
